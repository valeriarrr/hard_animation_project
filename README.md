## Описание проекта

Программа визуализирует фрактальный узор Омара Пола, также известный как «последовательность зубочисток». На каждом шаге к открытым концам предыдущих элементов добавляются перпендикулярные отрезки. Реализован автоматический зум, позволяющий наблюдать за ростом фрактала целиком. Визуализация выполнена в нежных пастельных тонах.

## Функциональные возможности

### Основной функционал
- 📐 Рекурсивное построение фрактала Омара Пола
- 🔍 Автоматический зум (масштабирование под размер окна)
- ▶️ Запуск и остановка анимации по кнопке

### Дополнительный функционал
- 🎨 Нежно-розовый интерфейс

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone ССЫЛКА БУДЕТ ПОЗЖЕ
cd hard_animation_project
```

### 2. Создание и активация виртуального окружения
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```
